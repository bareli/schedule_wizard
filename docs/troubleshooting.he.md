# פתרון בעיות ושאלות נפוצות

## פתרון בעיות

**האינטגרציה לא נטענת.**
: פותחים הגדרות ← מערכת ← יומנים ומסננים לפי `schedule_wizard`. גרסת Home Assistant המינימלית היא 2024.7.

**אירועים ביומן לא מפעילים כלום.**
: בודקים שנבחר יומן בהגדרות. בודקים שכותרת האירוע מכילה את שם האזור כמילים שלמות (שם של תו אחד או שניים חייב להיות כל הכותרת). אירועי יום שלם לא נספרים. אחר כך מפעילים רישום ברמת debug:

```yaml
logger:
  default: warning
  logs:
    custom_components.schedule_wizard: debug
```

**ברז נשאר פתוח אחרי הפעלה מחדש.**
: זה צפוי אם ההשקיה הפעילה השמורה אבדה (התקנה חדשה) או שהישות כובתה ידנית בזמן ההשבתה. השקיות רגילות נשמרות ונסגרות בסוף הזמן שתוכנן להן.

**"Unsupported domain" בקריאה לשירות.**
: מותרות רק ישויות מסוג `switch`, `valve`, `cover`, `input_boolean` ו-`light`.

**מופיעה אזהרה ב-הגדרות ← תיקונים.**
: מפסק של אזור או חיישן שמשמש בהגדרות נעלם (שונה שמו, הוסר, או שהאינטגרציה שלו לא נטענת). האזהרה מציינת את הישות, ונעלמת מעצמה כשהבעיה מתוקנת.

**דיווח על באג.**
: משתמשים ב-**Download diagnostics** (הגדרות ← מכשירים ושירותים ← Schedule Wizard ← ⋮). קובץ ה-JSON כולל אזורים, תוכניות, לוחות זמנים, מצב והיסטוריה אחרונה, בלי מזהה ה-webhook ויעדי ההתראות. מצרפים אותו לדיווח ב-[GitHub](https://github.com/bareli/schedule_wizard/issues).

## שאלות נפוצות

**אפשר להשתמש בזה גם לדברים שאינם השקיה, למשל תאורה חיצונית ל-N דקות?**
: כן. כל `switch`, `light`, `input_boolean`, `cover` או `valve` עובד.

**שני לוחות זמנים יכולים לפעול על אותו אזור באותו זמן?**
: לא. השקיה שנייה באזור שכבר פעיל מחליפה את הראשונה; הראשונה נרשמת כ-`cancelled`.

**מה קורה כשאירוע ביומן חוצה את חצות?**
: ההשקיה מתחילה בתחילת האירוע. המשך נלקח מהתיאור או מאורך האירוע. לחצות אין משמעות מיוחדת.

**הלוח עובד באפליקציה ובטלפון?**
: כן. התצוגה מתכווצת לעמודה אחת במסכים צרים.

**איפה הנתונים נשמרים, ואפשר לגבות אותם?**
: בקובץ `<config>/.storage/schedule_wizard.data`, JSON רגיל. הוא נכלל בכל גיבוי מלא של Home Assistant.

**איך מתחילים מחדש?**
: מוחקים את האינטגרציה (הגדרות ← מכשירים ושירותים ← Schedule Wizard ← ⋮ ← מחיקה) ומוסיפים אותה שוב. או מוחקים את `<config>/.storage/schedule_wizard.data` ומפעילים מחדש.

**האינטגרציה מוסיפה ישויות של זרימה, לחץ או עונה?**
: היא מוסיפה את הישויות שרשומות ב[מדריך העזר](reference.md#entities). זרימה, גשם וטמפרטורה מגיעים מחיישנים שבוחרים בהגדרות.
