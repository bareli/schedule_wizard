## Summary

SECURITY RISK, reasoned from code, not reproduced. An event whose summary merely contains a zone label, plan name or entity id starts that zone or plan; duration comes from the description or end minus start (max 1440). Calendars that accept invitations (Google, Outlook, CalDAV) add third-party events automatically, so an outsider who can invite the owner can start watering at a chosen time, subject to weather skips. Short labels such as 'a' or '1' match almost any event. No stored XSS from event text: the panel and card render with textContent and setAttribute, and no caller passes the html attribute of el().

**What changed** (`scheduler.py` `_summary_has`, `_match_valve`, `_match_cycle`): a zone label, plan name or entity id matches only as whole words of the event **summary** (case-insensitive, Unicode word boundaries, so Hebrew works; punctuation such as `-` `:` `,` `(` counts as a boundary). A label or name of 1 or 2 characters matches only when it is the entire summary. Longest match still wins. Description, location and attendees were never matched and still are not.

Backward compatibility: events whose summary is the label, or contains it as words ("Front lawn morning cycle"), behave as before. Events that only matched inside a longer word ("Front lawns", "Storefront", "Frontend", "Good mornings") no longer start watering; a zone named `a` or `B2` now needs an event titled exactly `a` / `B2`. Documented in README *Calendar event format* (with the advice to use a dedicated calendar when invitations are auto-accepted), the cycles section, troubleshooting, and info.md. CHANGELOG left to the release step.

Not done (from the finder's proposal, needs owner call): optional keyword-prefix option, organizer restriction (HA `calendar.get_events` does not return the organizer), a separate cap on event-derived duration (still capped at 1440 min as before). The panel's Settings hint "Events whose title contains a zone name ..." was left unchanged in 17 languages; it is still true for whole-word matches.
