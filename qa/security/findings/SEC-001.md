## Summary

The public, unauthenticated webhook accepts any entity id in SUPPORTED_DOMAINS (switch, valve, cover, input_boolean, light). It never checks that the entity is a registered zone, so the secret id operates every switch, light, cover (garage door, blinds) and valve in the HA instance for up to 1440 minutes, then calls turn_off / close on it. Reproduced.

## Steps to reproduce

As anyone holding the webhook id (no HA token), dev instance with zero registered valves:
1. POST /api/webhook/WEBHOOK_ID body {"entity_id":"input_boolean.zone_front","duration_minutes":<10^30>} -> 200 {"ok":true,"action":"run",...,"duration_minutes":1440}
2. POST body {"entity_id":"switch.does_not_exist","duration_minutes":1} -> 200 ok (the entity does not exist)
3. POST body {"entity_id":"light.nope","action":"stop"} -> 200 ok
4. Admin get_state showed an active run with source=webhook for the unregistered entity; stop_all cleaned it up; zone_front confirmed off.
Negative controls that held: lock.* and sensor.* -> 400 unsupported domain; GET -> 405; unknown id -> empty 200 (HA default).

## Expected

Webhook acts only on entities registered with add_valve, answers 4xx otherwise, and has a lower maximum duration than the 24 h service ceiling or a per-zone opt-in.

## Actual

Any entity in five domains is switched, registered or not. A cover is opened with open_cover; a switch or light is turned on for up to 24 h.

## Relevant files

custom_components/schedule_wizard/__init__.py lines 623-652 (_webhook_handler); const.py:127 (SUPPORTED_DOMAINS); scheduler.py:957 and 1685 (async_run_valve, _call_service_on).

## Fix prompt

In _webhook_handler, after _entity_in_supported_domain, require store.get_valve(entity_id) for run and stop (and valve enabled); return 404 {error: unknown zone} otherwise. Clamp duration to a webhook maximum. Tests: unregistered entity -> 4xx and no service call; registered entity still runs; stop of unregistered -> 4xx. Verify as the original (anonymous) caller, then check that a registered zone still runs from an automation using the existing URL; note the behaviour change in the changelog.
