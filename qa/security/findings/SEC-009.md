## Summary

Any calendar event whose title contains a zone name starts the zone; an auto-accepted invitation could therefore start irrigation. Fix adds an optional keyword prefix.

Filed as an issue only; the issue body and the fixer's handback are the source of truth. This record carries the verification verdict.

## Verdict (2026-10-01, qa-security-expert, fresh finder role, fixed build on 8170)

**PASS.** Local calendar created on the dev instance for the test and removed afterwards.

- No keyword: "ENG front" and "Meeting about ENG herbs" both started (whole-word match as v0.14.1).
- Keyword "water:" (saved as typed with spaces, stored stripped): "ENG front" and "Meeting about ENG herbs" did not run; "Water: ENG back" ran; "wAtEr:ENG herbs" ran (case-insensitive, no space needed); "ENG herbs water:" (keyword not a prefix) did not run.
