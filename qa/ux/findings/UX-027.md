# UX-027 Run dialog: the This time only percent select is labelled Minutes but offers percentages

## Observation

In the run dialog's "This time only" form the select is announced as combobox "Minutes" with options "50 %", "75 %", "As planned", "125 %", "150 %", "200 %" (string `once.minutes`). A screen reader user hears "Minutes" and then percentages. Visible label and name match, so SC 2.5.3 passes, but the label does not describe the control (SC 3.3.2 is arguable).

Also seen: after Save fails ("That time has already passed today.") focus stays on Save and the message is read through `role=alert` with `aria-invalid` + `aria-describedby` on the time field (works); the error is not cleared when the time is edited, and focus is not moved to the invalid time field (the Settings Weather tips form does move focus).

## Suggestion

Rename `once.minutes` to "Length" ("Watering length"), clear the error on input, and call `timeIn.focus()` after `setFieldError`.
