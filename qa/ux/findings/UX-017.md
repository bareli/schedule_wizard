## Problem

The day buttons run Mon, Tue ... Sun in every language. In Hebrew (HA `locale.first_weekday = language`, Sunday-first) the row reads ב׳ ג׳ ד׳ ה׳ ו׳ ש׳ א׳, so Sunday, the first day of the Israeli week, is the last button, and at 320 px the row wraps with ש׳ and א׳ orphaned on a second line. US users (Sunday-first) get the same Monday-first order. The week view on Home correctly starts on today.

## Why it matters

Hebrew is the owner's language and the first test locale; Sunday is a normal watering day. Users scan for א׳ at the start of the row.

## Evidence

![Hebrew 320: Mon-first, Sun last, second row wraps](https://github.com/bareli/schedule_wizard/blob/main/qa/evidence/UX-017-weekday-pills-he-320.png?raw=1)

## Recommendation

Order the buttons from `hass.locale.first_weekday` (language / monday / sunday ...). Keep a single line at 320 px (smaller gap or 7-column grid). The strings exist, sonnet can fix.
