## Problem

After one temperature skip, Reports > Per-plan totals shows **Skipped 1** for ENG plan, but the **Skip reasons** block shows Rain 0, Moisture 0, Overlap 0, Failed 0, Cancelled 0. The new v0.14.0 reason has no tile (panel.js `skipReasons` holds skipped_rain, skipped_moisture, skipped_overlap, failed_to_open, cancelled). The same gap already exists for forecast, rain delay, condition and manual skips, but 0.14.0 adds one more reason that cannot be found.

## Why it matters

The one place meant to answer "why was it skipped" gives an all-zero answer for a skip the user just saw, which looks like a counting bug.

## Evidence

![Reports: Skipped 1 in the plan table, all reasons 0](https://github.com/bareli/schedule_wizard/blob/main/qa/evidence/UX-003-reports-skip-reasons.png?raw=1)

## Recommendation

Add a tile **Temperature (0 %)** (and, while there, forecast / condition / manual), or one catch-all **Other**, so the tiles sum to the skipped total. The status string exists (status.skipped_seasonal_zero); a tile label key is needed in 17 languages (tests/test_i18n.py). Failed / Cancelled are not skip reasons: consider relabelling the block.

## Kind

Works, could be better. Wording is quotable, so sonnet can fix it once the owner picks the tile set.
