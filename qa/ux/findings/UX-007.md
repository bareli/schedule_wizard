## Problem

With three zones the accessibility tree lists `button "Water now"` three times, `button "Less time"` / `button "More time"` three times, `button "Skip day"` three times (week), `button "Edit zone"`, `button "Delete"` and `switch "Enabled"` per row, and in the card `button "Run"` / `button "Stop"` per zone. The zone cards are `article` elements with no label, so the context is not exposed either (the only mouse clue is `title` on Skip day, which is not the name).

## Why it matters

A screen-reader user who lists buttons, or jumps from control to control, cannot tell which zone "Water now" starts: starting the wrong valve is a physical outcome (water). Not a clear WCAG failure (reading order gives context), so UX ISSUE; related to 2.4.6.

## Evidence

![three identical Water now buttons, stepper buttons and Skip day links](https://github.com/bareli/schedule_wizard/blob/main/qa/evidence/BUG-006-primary-colour-contrast-light.png?raw=1)

The same Home screenshot as BUG-006 (three zone cards: Water now, "-" and "+" repeated; Skip day repeated in the week). Names from the Chromium accessibility tree, 2026-10-01, for example `article: ... button "Less time" ... button "More time" ... button "Water now"` repeated per zone.

## Recommendation

`aria-label="Water now, Front lawn"` (visible text stays), name the cards with `aria-labelledby` the zone title, include the day in "Skip day" ("Skip day, Fri 10/2"), include the schedule in the toggle's name, and the zone in the card's Run / Stop.

## Handback (qa-developer, 2026-10-01)

**Fix** (commit `3ae4dc7`, `www/panel.js`): a `_named(action, name)` helper over the existing `card.action_for` key ("{action}: {zone}", 17 languages): visible text first (WCAG 2.5.3), then what the control acts on. Home zone cards: `article` named by the zone title; "Water now: <zone>", "Less time: <zone>", "More time: <zone>", "Stop: <zone>". Week: "Skip day: <day date>". Zones tab: card named by the zone; "Edit zone: <zone>", "Delete: <zone>", "+ Add time: <zone>". Schedule rows: the switch "Enabled: <name>, <when>", and Skip next / Undo / Edit / Delete the same. Plan cards: named card, "Run now: <plan>", Pause / Resume / Stop / Edit / Enable / Disable / Delete, "+ Add time: <plan>". Wizard steppers: "Less time: <zone>". The card's Run / Stop were already done in #47.
