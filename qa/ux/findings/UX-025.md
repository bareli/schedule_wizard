## Problem

1. A changed run shows "changed for this day" in the week and "What changes this run: Moved to 5:20 AM for this day" in the dialog. Neither says what it was before (7:30 PM), so a week later nobody can tell whether the change was intended.
2. The Minutes select offers "50 % / 75 % / As planned / 125 % / 150 % / 200 %". Gardeners think in minutes, and with a boost active "As planned" is ambiguous: tomorrow's Herb bed dialog reads "5 min", "Expected: 7 min", "Water more / less: +30 %", then "As planned" (5 or 7?), and 150 % of which?
3. "Skip this run" appears only for the schedule's next run (panel.js ~1736, `isNext`). Monday's run offers Close / Edit schedule / Save change, no skip and no word why; the only way to skip it is Skip day, which skips every zone that day.
4. Single-zone runs repeat the zone under "Zones" (title "Herb bed", then "Zones: Herb bed 8 min").

## Why it matters

Moving one run and skipping one run are the everyday adjustments; the user should not need to remember the original time or do percentage arithmetic.

## Recommendation

- Tag **"moved from 7:30 PM"** / **"8 → 12 min this day"**; dialog **"Moved from 7:30 PM to 5:20 AM for this day"**.
- Options with minutes: **"As planned (7 min)"**, **"50 % (4 min)"**, "75 % (5 min)" ..., computed from the expected minutes.
- Offer **"Skip this run"** on every future run (unskip already takes a date), or if not possible show "Only the next run can be skipped here. Use Skip day for {day}."
- Hide the Zones list when the run has one zone.
