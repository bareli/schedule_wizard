## Problem

1. The **Water more / less** button (and Pause for rain) only exists on the status card when nothing is watering and no boost or rain pause is set (panel.js ~1893-1904, idle branch only). In the morning, when the user is in the garden noticing the heat, a 45-min drip zone or a 2-h plan is running, and the button is simply not there. Nothing says where it went.
2. The chooser applies to every scheduled run but shows no preview of the result ("Front lawn 15 → 20 min"), only "+20 %, 2 days".
3. Settings offers three features that each say "more water when hot" with no hint how they relate: **"Water more when it's hot"** (seasonal temperature factor, automatic), **Weather tips > "Extra water on hot days"** (the size of a suggested boost), and Home **"Water more / less"** (manual boost). The heat tip does not look at the first one (scheduler.py `tips()`, ~line 2324: only an existing boost suppresses it), so a user who already has the automatic temperature factor on is still told to add another 30 %.

## Why it matters

"Water more in a heat wave" is one of the four real tasks for this release; the entry point is hidden exactly when the user is most likely to look for it, and the settings make it unclear which mechanism to use.

## Evidence

![Status card while Drip line trees waters: Stop watering only, no Water more / less](https://github.com/bareli/schedule_wizard/blob/main/qa/evidence/UX-023-running-no-water-more-en-1440.png?raw=1)

The running state also had a planned boost; per code the button is hidden in both states (`if (!this._boostActive())` inside the idle `else` branch).

## Recommendation

- Put "Water more / less" (and "Pause for rain") in a row that is always visible, e.g. under the status card or in the "This week" header, regardless of what is running. When a boost is set, the same place shows the banner with "Change" and "End now".
- In the chooser, add a preview line: "Next runs: Front lawn 15 → 20 min, Back garden 20 → 26 min".
- Settings, Weather tips group description: "Tips only suggest. Nothing changes until you press a tip's button." Rename "Extra water on hot days" to **"Suggested extra on hot days"**. In "Water more when it's hot" add: "Automatic, every day. If this is on, heat tips are not shown." (and suppress heat tips when it is on, like rain tips are suppressed when "Skip when rain is forecast" is on).
