## Summary

Every message the panel shows through `_toast()` ("Zone name required", "Done", server errors, "Pick a switch") is invisible. The toast is appended to `document.body` but its CSS lives in the panel's own styles, so it renders as plain static text under the page, at y=900 on a 900 px viewport, for 2.8 s. A gardener who presses Save on an invalid form sees nothing happen. Affects all 17 languages and every form that validates through a toast (19 call sites). Contradicts the intent of the CSS rule (`.toast { position: fixed; bottom: 20px ... }`, panel.js ~277).

## Steps to reproduce

1. Open the panel, Zones, Edit zone on any zone.
2. Clear Zone name. Press Save.
3. Look at the screen for the next 3 seconds.

## Expected

A visible pill at the bottom of the screen saying "Zone name required" (the CSS written for it), ideally with the field highlighted. Source: panel.js `.toast` rule; the same pattern works for "Skip day" feedback only because the state also changes on screen.

## Actual

Dialog stays open, no change, no message in the viewport. DOM: `div.toast` with parent BODY, computed position static, rect y=900 h=17 (page scrollHeight 917). Full-page capture shows the text stranded at the bottom-left under the page.

## Evidence

![Zone name required stranded below the viewport, bottom-left](https://github.com/bareli/schedule_wizard/blob/main/qa/evidence/BUG-012-error-toast-off-screen.png?raw=1)

Measured: `document.querySelector('.toast')` position static, top 900, innerHeight 900. Hypothesis (not proven): the stylesheet is scoped to the panel's shadow root and the toast is created outside it; fix is to append the toast inside the panel root or inject the rule into document.

## Recommendation

Append the toast to the panel's own root (or the same node that carries the styles), then re-check LTR and RTL. Add inline field errors for the two most common validation failures (name, switch). Test: unit test that a rejected save leaves a visible toast in the panel root.

custom_components/schedule_wizard/www/panel.js (`_toast`, `.toast` CSS), 19 `_toast(` call sites.
