## Summary

The card registers `window.customCards` with the fixed English description "Dashboard card for Schedule Wizard: active runs + quick run." It is shown in every language and no longer describes the card (zone list with Water now / Stop, next run, rain pause).

## Steps to reproduce

1. Dashboard in Hebrew or German.
2. Read `window.customCards` (what the card picker shows).

## Expected

A current description in the user's language (the 17 panel languages).

## Actual

he, de and en all read `Dashboard card for Schedule Wizard: active runs + quick run.`

## Evidence

Evidence unavailable as a picture: the text was read from `window.customCards` on 8188 in he / de / en (quoted above); the picker only shows that string.

## Relevant files

custom_components/schedule_wizard/www/card.js, www/i18n.js

## Handback (qa-developer, 2026-10-01)

Fix commits `509425d` on `fix/v0.15.0-polish`. Full handback with recipe and environment: issue #84.

**Fix** (commit `509425d`, `www/card.js`, `www/i18n.js`): the `window.customCards` entry's `description` is a getter that translates `card.picker_description` in the signed-in user's language (from `home-assistant`.hass, else the saved `selectedLanguage`, else the browser) when the picker reads it. New key in all 17 languages; it uses each language's own button words (Water now / Stop watering). English: "Your zones on the dashboard: what is watering, the next run, and Water now or Stop watering for each zone."
