## Summary

In the timeline, a bar that overlaps another run is the red `--sw-danger-fill` (175,54,44) instead of teal (0,115,149). The bar text is only "N min" in both cases; the only visible cue is the hue plus a legend swatch. Both fills carry white text at 5.4:1 and 6.2:1 (pass), but the two hues are not distinguishable by lightness, so a colour-blind user cannot tell which bars clash. The text equivalent exists only in `aria-label` and `title` (a mouse tooltip, not shown for keyboard focus). The List view does have a text tag ("Overlaps ..."), so this is timeline-only.

## Steps to reproduce

Home > This week > Timeline > Mon (two clashing runs, 5:00 AM Drip line trees 45 min and 5:20 AM Herb bed 8 min).

## Fix

Add a non-colour cue to clashing bars: a visible prefix such as "!" or a warning glyph in the bar, or a stripe pattern / 2 px inner border, plus a legend entry that shows the same marker.
