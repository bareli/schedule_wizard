## Summary

The pause state is drawn with `--sw-warn: var(--warning-color, #b45309)`. In Home Assistant's default theme `--warning-color` is `#ffa600`, so text in the "Paused for rain" pill, the "Paused" zone pills and the week-view rain tag is orange on a pale orange tint. The state is the main reason a user sees their watering stopped.

## Steps to reproduce

1. Home tab with a zone and a plan. Activate "Pause for rain", choose 24h (cleared again after the measurement).
2. Read the computed colour and background of `.pill.pause` and `.wk-tag` in light and dark theme.

## Expected

4.5:1 for text under 18.66 px regular (WCAG 1.4.3). Source: WCAG 2.1 AA.

## Actual

| Element | Size | Light theme | Dark theme |
|---|---|---|---|
| `.pill.pause` "Paused for rain" (`#ffa600` on `rgb(235,215,200)`) | 12px / 500 | **1.41:1** | 7.97:1 |
| `.wk-tag` "Paused for rain" (week view, `#ffa600` on `rgb(245,238,233)`) | 11px / 500 | **1.71:1** | 9.15:1 |
| zone-card "Paused" pill (same colours as `.pill.pause`, visible in screenshot) | 12px | about 1.5:1 (same colours on a white card, not separately computed) | not computed |

The fallback `#b45309` in the stylesheet would pass; it is never used because the HA theme defines `--warning-color`.

## Evidence

![Paused for rain pill, Paused zone pills and rain tag in the light theme](https://github.com/bareli/schedule_wizard/blob/main/qa/evidence/BUG-005-paused-for-rain-contrast-light.png?raw=1)

Desktop 1280x900, light theme, English, HA default theme (`--primary-color` `#009ac7`). Rain pause active for 24 h; the three pills and the week tag are barely legible.

## Likely root cause

`.pill.pause`, `.wk-tag.warn`, `.wk-run.rain .wk-tag` and `.badge.warn` use the theme warning colour directly as text colour. Likely.

## Relevant files

`custom_components/schedule_wizard/www/panel.js` STYLES (`--sw-warn`, `.pill.pause`, `.wk-tag`, `.badge.warn`).

## Recommended remediation

Use a text colour that reaches 4.5:1 on its tint in both themes (for example a darker amber in light theme, or the theme colour only for the border/background and `--primary-text-color` for text). Product call on the palette, hence model:opus.

## Regression test

A11Y-04: browser contrast measurement of `.pill.pause`, `.wk-tag`, `.badge.warn` in both themes. A pytest check can only pin CSS strings, not the rendered ratio.
