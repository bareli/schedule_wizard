Declared standard: none in `qa/PROJECT.md`, WCAG 2.1 AA assumed. Tooling: Chromium 153 + Playwright 1.63.0 (accessibility tree). **No real screen reader was available.**

## Summary

Each condition row has four controls: entity, attribute, operator (select) and value. The operator `<select>` has no label at all. The other three have only a `placeholder`, which disappears once typed into and is not a persistent visible label.

## Steps to reproduce

1. Zones tab, "+ Add time", press "+ Add condition".
2. Read the accessibility tree of the dialog and `labels` / `aria-label` of the four controls.

## Expected

Every control has a programmatic name and a persistent visible or `aria-label` name (4.1.2, 3.3.2). Source: WCAG 2.1 A.

## Actual

Accessibility tree: `textbox "sensor.example"`, `textbox "attribute (optional)"`, `combobox:` (no name), `textbox "value"`, `button "Remove condition"`. `labels.length` is 0 for all four; `aria-label` is null. With several rows, nothing says which row a field belongs to. The attribute placeholder is also cut off at normal width ("attribute (op").

## Evidence

![condition row with placeholders only and a select without a label](https://github.com/bareli/schedule_wizard/blob/main/qa/evidence/BUG-007-condition-row-no-labels.png?raw=1)

Desktop 1280x760, light theme, English. One condition row added to "Add watering time".

## Likely root cause

`panel.js` L2076-2098 builds the row without labels. Likely.

## Relevant files

`custom_components/schedule_wizard/www/panel.js` (`renderConditions`), `www/i18n.js` (17 languages).

## Recommended remediation

Add `aria-label` to the four controls (reuse the existing text of the placeholders; the operator needs a new string in all 17 languages, hence model:opus for wording) and append the row number to the remove button's label.

## Regression test

A11Y-06: accessibility-tree check that every control in `.cond-row` has a name. A pytest test can pin the i18n keys only.

## Fix prompt

Fix BUG-007 in Schedule Wizard. Problem: `.cond-row` controls are unnamed (select) or named only by placeholder. Expected: each has an accessible name including the row number (WCAG 4.1.2, 3.3.2); new strings in all 17 languages (tests/test_i18n.py). Reproduce: "+ Add time", "+ Add condition", read the tree. File: panel.js `renderConditions`.
