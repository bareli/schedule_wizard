## Summary

Past runs in the week view are drawn with `.wk-run.past { opacity: 0.55; }` (panel.js STYLES). The verifier measured the text at 3.83:1 and the rain tag at 2.45:1 in the light theme (opacity composited, see qa/knowledge/a11y-measurement.md). The runs are still buttons (they open the run dialog), so their text needs 4.5:1.

## Steps to reproduce

1. Home tab, light theme, 1440 px, English.
2. A day with a run earlier today (here: Front lawn 06:00, Herbs 07:00).
3. Measure the text of the greyed runs with the 0.55 opacity composited over the card.

## Expected

Past runs are told apart by a muted colour token that keeps text at or above 4.5:1 (and the rain tag readable), not by opacity.

## Actual

Computed on 8188: `opacity: 0.55`, text `rgb(20,20,20)` on `#fff`, about 3.8:1 after compositing; rain tag 2.45:1 (verifier).
