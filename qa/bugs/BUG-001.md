## Summary

An enabled every-N-days schedule whose `start_date` is more than 31 days in the future has no next run in the
zone card ("No schedule yet"), the home status card ("Nothing scheduled yet"), `valves[].next_run` and
`sensor.schedule_wizard_next_schedule` (state `unknown`). The schedule itself is stored correctly: it appears in the
calendar entity. Affects users who set a distant start date (for example a spring programme entered in winter) and
see an apparently empty zone.

## Steps to reproduce

1. Register `input_boolean.zone_back` as a zone, with no other schedule on it.
2. `schedule_wizard.add_schedule`: `valve_entity_id: input_boolean.zone_back`, `time: "07:00"`, `every_n_days: 7`,
   `start_date: "2026-12-20"` (today is 2026-10-01). The panel date field allows the same.
3. Open the panel Home tab; read `schedule_wizard/get_state` `valves[].next_run`; wait 30 s and read
   `sensor.schedule_wizard_next_schedule`.
4. Query `calendar.schedule_wizard_watering_schedule` for 2026-12-19 to 2026-12-22.

## Expected

Next run = the first run, 2026-12-20 07:00. Source: README ("next-run times, the week view, calendar and
`sensor.schedule_wizard_next_schedule` all follow it") and plan SCH-04. Inference: a future start date is the next run.

## Actual

Zone card "No schedule yet", status card "Nothing scheduled yet", `next_run` null, sensor `unknown`. The calendar
returns the 2026-12-20 07:00 event.

## Evidence

Threshold measured on 2026-10-01: `start_date` 2026-10-31 shows "Sat 07:00", 2026-11-01 (31 days ahead) shows "Sun 07:00",
2026-11-02 (32 days) shows None, 2026-11-10 shows None.
Calendar for the 2026-12-20 case: `{'start': {'dateTime': '2026-12-20T07:00:00+02:00'}, 'summary': 'ENG back', ...}`.
Sensor after the 30 s poll: state `unknown`.

## Screenshots

## Likely root cause

`planner.next_fire` and `planner.next_occurrence` search only `NEXT_RUN_DAYS = INTERVAL_MAX_DAYS + 1` (31) days from
now, enough for a running interval but not for a distant start date. The measured 31/32-day threshold matches.

## Relevant files

`custom_components/schedule_wizard/planner.py` (`next_fire`, `next_occurrence`, `NEXT_RUN_DAYS`); callers in `sensor.py`,
`__init__.py` (`next_run` in get_state), `calendar.py` (`event`).

## Recommended remediation

For an interval schedule start the search at `max(today, start_date)` and look ahead N days from there.
Weekday schedules unchanged.

## Regression test

SCH-04: add a case with `start_date` 60 days ahead, assert `next_fire` returns the start date at the schedule time.
