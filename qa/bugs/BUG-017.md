## Summary

A zone with exactly one run in the last 7 days reads "1 runs / 45 min last 7 days" (en), "1 Läufe / 45 Min. in den letzten 7 Tagen" (de), "1 הפעלות ..." (he). Known v0.14.1 candidate, reproduced. Also listed as item 2 of the combined UX-018; this record is the defect itself so it can be fixed without waiting for the rest of UX-018.

## Steps to reproduce

1. Add a zone, Water now, Stop (one run in 7 days).
2. Zones tab: read the zone's second line. Switch the profile language to Deutsch and Hebrew.

## Expected

Singular for 1: "1 run", "1 Lauf", "הפעלה אחת" (or "1 הפעלה"), plural otherwise, in all 17 panel languages. Source: the panel already formats plurals elsewhere through I18N; known-issue list in the cycle brief.

## Actual

```
en  Last: 12s ago • 45 min • cancelled • 1 runs / 45 min last 7 days
de  Zuletzt: vor 25 s • 45 Min. • abgebrochen • 1 Läufe / 45 Min. in den letzten 7 Tagen
he  אחרון: לפני 37 שנ׳ • 45 דק׳ • בוטל • 1 הפעלות / 45 דק׳ ב־7 הימים האחרונים
```

## Likely root cause

`www/i18n.js` key `valves.week` is a single string `"{runs} runs / {min} min last 7 days"` in every language; `panel.js` `_zoneAdminCard` (line ~1395) calls `this._t("valves.week", { runs, min })` with no plural selection.

## Relevant files

- `custom_components/schedule_wizard/www/i18n.js` (`valves.week`, 17 languages)
- `custom_components/schedule_wizard/www/panel.js` (`_zoneAdminCard`)

## Recommended remediation

Split into `valves.week_one` / `valves.week_other` (or use `Intl.PluralRules(lang)` with `one`/`other` keys) for all 17 languages; keep `tests/test_i18n.py` green. Same check for other "{n} runs" strings (Reports "10×" is fine).

## Regression test

I18N-02: zone with 1 run shows "1 run" / "1 Lauf" / Hebrew singular; 2 runs show the plural.
