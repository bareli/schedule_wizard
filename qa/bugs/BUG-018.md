## Summary

After a watering plan is deleted, its past history rows in Recent activity read "459e553ab811: plan cancelled" and the zone rows it ran read "plan: 459e553ab811". The 12-hex-digit id means nothing to the user. Known v0.14.1 candidate, reproduced in en, de and he.

## Steps to reproduce

1. Programs: create plan "QAE gone" with one zone; Run now; Stop.
2. Delete the plan.
3. Home > Recent activity.

## Expected

The plan's name as it was when it ran (for example "QAE gone: plan cancelled", "plan: QAE gone"), or a neutral "Deleted plan". Source: everywhere else the panel shows names, not ids (README "entity IDs only in small print", v0.11.0); known-issue list in the cycle brief.

## Actual

```
en  459e553ab811: plan cancelled / service ... QAE four: cancelled / plan: 459e553ab811
de  459e553ab811: Plan abgebrochen / Dienst ... QAE four: abgebrochen / Plan: 459e553ab811
he  459e553ab811: התוכנית בוטלה / שירות ... QAE four: בוטל / תוכנית: 459e553ab811
```

## Evidence

![Recent activity shows 459e553ab811 for a deleted plan](https://github.com/bareli/schedule_wizard/blob/main/qa/evidence/BUG-018-deleted-plan-raw-id.png?raw=1)

## Likely root cause

History rows store only the cycle id (`valve_entity_id` = cycle id for `cycle_*` rows; `source` = `cycle:<id>` for step rows); the panel resolves the name from the current `cycles` list and falls back to the id when the plan is gone (`_activitySentence` / `_sourceLabel` / `_valveName`). The plan's name is not persisted in the row.

## Relevant files

- `custom_components/schedule_wizard/storage.py` (`async_record_run`)
- `custom_components/schedule_wizard/scheduler.py` (cycle history rows)
- `custom_components/schedule_wizard/www/panel.js` (`_activitySentence`, `_sourceLabel`, `_valveName`, Reports per-plan table, CSV `target_label`)

## Recommended remediation

Product call between: store a `name` / `label` on cycle history rows at write time (new rows only; old rows fall back), or render a localised "Deleted plan" when the id is unknown. Hence model:opus. Apply the same to the CSV `target_label` and the Reports per-plan table.

## Regression test

PANEL-01: delete a plan that has history; Recent activity, Reports and CSV show its name (or "Deleted plan"), never the hex id.
